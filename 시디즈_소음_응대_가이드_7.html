💡 고객에게 dB 수치 직접 언급 자제 — 일상 비교 언어로 번역하세요. dB는 내부 판단용. "제가 보기에"가 아닌 "저희 소음 표준 가이드에 따르면"으로 근거를 명시하고, 판단이 어려우면 앱 측정 또는 영상으로 고객이 직접 체감하게 유도하세요.
🎯 상황: 헤드레스트·좌판 조절 시 마찰음에 민감하게 반응하는 경우
① 공감
"고객님, 의자 기능을 조절하실 때 들리는 소리 때문에 놀라셨군요. 충분히 이해합니다."
② 일상 비교로 안내 (dB 수치 언급 X)
"시디즈 제품은 정밀한 부품들이 맞물려 작동하기 때문에 조절 시 일정 수준의 마찰음이 발생할 수 있습니다. 저희 소음 표준 가이드 기준으로, 좌판이나 헤드레스트 조절 시 나는 작동음은 일상적인 대화 소리나 조용한 사무실 정도의 수준으로 정상 범위에 해당합니다."
③ 마무리
"제품 결함이 아니라 기능이 정상적으로 작동하며 발생하는 소리입니다. 그래도 불편하시면 교환·환불 절차도 안내드릴 수 있습니다. 어떻게 도와드릴까요?"
✓ 공감 → 일상 비교 → 선택지 순서를 지키세요. '소음' 대신 '작동음'·'마찰음'으로 표현합니다.
🎯 상황: 조용한 집·공부방·야간에 사용하며 작은 소리도 크게 느끼는 경우
① 공감
"조용한 환경에서 사용하시다 보니 작은 소리도 더 크게 느껴지실 수 있습니다. 충분히 이해합니다."
② 일상 비교 안내 (dB 수치 언급 X)
"저희 제품의 기본 작동음은 냉장고에서 나는 웅~ 하는 소리와 비슷한 수준입니다. 평소에는 잘 못 느끼시다가, 주변이 아주 조용해지면 냉장고 소리도 더 크게 들리시는 것처럼, 의자 작동음도 같은 이유로 더 신경 쓰이실 수 있어요."
③ 앱 측정 제안 (고객이 직접 체감)
"혹시 더 직접적으로 확인해 보시고 싶으시다면, 스마트폰 앱으로 간단히 측정해 보실 수 있습니다. 아이폰이시면 건강 앱 → 소음 측정 기능을, 안드로이드이시면 앱스토어에서 '소음 측정'을 검색해서 설치하신 후, 의자 옆에 폰을 놓고 동작해 보시겠어요?"
④ 측정값 확인
"측정값이 나오시면 저한테 말씀해 주세요. 저희 정상 기준과 비교해서 바로 안내드리겠습니다. 수치 자체보다는 '아, 이 정도 소리구나' 하고 직접 느껴보시는 게 제일 정확하거든요."
✓ 앱 측정은 고객 스스로 체감하게 하는 용도입니다. 측정 환경마다 오차가 있으니 수치로 판정하지 말고, 고객이 "이 정도구나" 납득하도록 돕는 도구로 활용하세요.
🎯 상황: '딸깍', '덜컹' 등 불량 소음 의심 증상을 호소하는 경우
① 공감
"말씀하신 소리는 저희가 소음 표준 가이드에서도 주의 깊게 확인하는 부분입니다. 불편드려 죄송합니다."
② 정상/불량 구분 질문
"정상 작동음은 동작과 함께 일정하게 나지만, 이상 소음은 예측하기 어렵거나 특정 자세·각도에서만 반복됩니다. 혹시 소리가 날 때 진동이 함께 느껴지시거나, 특정 방향으로 기울일 때만 나는 편인가요?"
③ 앱 측정 제안 (이상 의심 시)
"지금 바로 확인해 보실 수 있는 방법이 있는데요. 스마트폰에서 소음 측정 앱을 켜시고 의자 옆에 폰을 놓은 채로 소리가 나는 동작을 해보시겠어요? 측정값을 알려주시면 저희 기준과 비교해 드릴게요."
④ 영상 요청 (최종 판단)
"가장 정확한 확인을 위해 소리가 나는 동작을 짧게 영상으로 찍어서 카카오톡 [시디즈 고객센터] 또는 이메일(cs@sidiz.com)으로 보내주시면, 저희 정상음과 비교 검토 후 AS 접수를 도와드리겠습니다."
⚠ 앱 수치만으로 불량 판정하지 마세요. 영상 확인 후 판단하는 것이 원칙입니다.
🎯 상황: 강한 불만으로 객관적 근거·공식 기준을 요구하는 경우
① 기준 근거 제시
"네, 고객님. 시디즈는 ISO 소음 측정 원칙(A-가중치)을 준수하여 제품별 소음 표준 가이드를 운영하고 있습니다. 제가 개인적으로 판단하는 것이 아니라 이 기준에 근거해서 안내드리고 있습니다."
② 일상 비교로 풀어서 설명
"T61 기준으로 각 부위 작동음은 조용한 사무실에서 키보드 치는 소리부터 일상 대화 수준을 정상 범위로 보고 있습니다. 지금 고객님이 느끼시는 소리가 그 범위 안이라면 기능적 이상으로 보기 어렵습니다."
③ 고객 직접 확인 제안
"제 말씀만으로는 납득이 어려우실 수 있어서, 고객님이 직접 확인하실 수 있는 방법을 안내드릴게요. 스마트폰 소음 측정 앱(아이폰: 건강 앱 내 소음 측정 / 안드로이드: '소음 측정' 검색)으로 측정해 보시거나, 소리가 나는 동작을 영상으로 보내주시면 저희 기준과 정밀 비교해 드리겠습니다."
✓ 근거 요구 고객에겐 직접 체감할 수단(앱·영상)을 제안하는 것이 가장 효과적입니다. "믿으세요"보다 "직접 확인해 보세요"가 훨씬 강합니다.
🎯 상황: 전화만으로 판단이 어려울 때 — 앱 측정 또는 영상 요청
앱 측정 안내 — 아이폰
"아이폰 사용하시면 기본 앱 중에 소음 측정 기능이 있습니다. 건강 앱 → 듣기 → 소음 측정 순서로 들어가시면 되고요. 의자 옆에 폰을 놓고 소리가 나는 동작을 해보신 후 수치를 알려주시겠어요?"
앱 측정 안내 — 안드로이드
"안드로이드 스마트폰이시면 플레이스토어에서 '소음 측정' 또는 'Decibel X'로 검색하시면 무료 앱이 있습니다. 설치하신 후 의자 옆에 폰을 놓고 소리가 나는 동작을 해보시고 수치를 알려주시면 비교해 드릴게요."
앱 측정 결과 확인 후
"수치 자체가 정확하진 않지만, 저희 정상 기준과 크게 차이가 없다면 안심하셔도 됩니다. 만약 수치가 많이 높게 나오거나 소리가 계속 신경 쓰이신다면 영상도 같이 보내주시면 더 정밀하게 확인해 드릴 수 있어요."
영상 요청 안내
"소리가 나는 동작을 10~20초 정도 촬영해서 카카오톡 [시디즈 고객센터] 또는 이메일(cs@sidiz.com)으로 보내주시면 빠르게 확인해 드리겠습니다. 촬영 시 소리 나는 부위를 가까이 찍어주시면 더 정확합니다."
⚠ 앱 측정은 체감 보조 도구입니다. 측정 환경(주변 소음·폰 위치·거리)에 따라 오차가 크므로 수치만으로 불량 판정하지 마세요. 최종 판단은 반드시 영상 확인 후 합니다.

3
영상·사진 첨부 요청 채팅 강점
소음 발생 동작 영상 → 채팅창에 바로 업로드 요청 / 부위 클로즈업 사진
4
미디어 확인 → 정상/불량 판단
영상 확인 후 dB 기준표 대조 → 정상 작동음이면 프롬프트 즉시 안내 / 불량이면 처리 방향 결정
5
처리 안내 + 대화 기록 보관

📝 롤플레잉 시나리오 — 4가지 상황
🎭상황 1 — 전화: "헤드레스트 조절할 때마다 소리가 너무 커요. 불량 아닌가요?"
▶ 훈련 포인트
  • '소음' 대신 '작동음'으로 표현하기
  • dB 수치 고객에게 직접 언급 자제
  • 일상 비교(키보드·대화 소리)로 설명
  • 7일 이내라면 교환/환불 옵션 병행 안내
▶ 핵심 멘트
✓"저희 소음 표준 가이드 기준으로, 헤드레스트 작동음은 조용한 사무실 키보드 소리 정도로 정상 범위입니다."
🎭상황 2 — 채팅: "밤에 공부할 때 쓰는데, 조금만 움직여도 소리가 신경 쓰여요."
▶ 훈련 포인트
  • 조용한 환경 → 상대적 체감 큰 상황 인식
  • 냉장고 소리 비유로 일상 비교
  • 앱 측정 제안 → 고객 스스로 체감
  • 메시지 짧게 1~2줄씩 나눠서 전송
▶ 핵심 멘트
✓"냉장고 웅~ 하는 소리와 비슷한 수준이에요. 📱 소음 측정 앱으로 직접 확인해 보시겠어요? 수치 알려주시면 기준과 비교해 드릴게요."
🎭상황 3 — 전화: "의자 뒤로 기울일 때 딸깍딸깍 소리가 반복해서 나요."
▶ 훈련 포인트
  • 반복·불규칙 여부 추가 질문
  • 앱 측정으로 1차 확인 유도
  • 최종 판단은 영상 확인 후
  • 앱 수치만으로 불량 판정 금지
▶ 핵심 멘트
⚠"소음 측정 앱으로 수치 확인해 주시고, 영상도 보내주시면 저희 정상음과 비교해서 바로 판단해 드릴게요."
🎭상황 4 — 전화: "정상이라고 하는데 무슨 근거예요? 객관적인 기준이 있나요?"
▶ 훈련 포인트
  • ISO 소음 측정 원칙 근거 제시
  • 일상 비교 언어로 기준 풀어서 설명
  • 앱 측정 또는 영상으로 직접 확인 유도
  • "믿으세요" → "직접 확인해 보세요"
▶ 핵심 멘트
✓"ISO 기준 소음 가이드에 따른 안내입니다. 직접 확인해 보시겠어요? 📱 소음 측정 앱이나 영상으로 바로 비교해 드릴게요."
